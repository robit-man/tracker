Tracker background storage

The extension keeps encrypted retained copies available in a managed pinned Tracker tab. Ordinary Tracker tabs can close. The browser must stay open.

Testing packages: store listings are not published yet, and the Firefox package is unsigned. Installation currently requires the manual steps below.

Chrome, Chromium or Edge

  1. Download the Chromium package and extract it into a folder.
  2. Open chrome://extensions or edge://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.

Firefox

  1. Download the Firefox package and extract it.
  2. Open about:debugging#/runtime/this-firefox and choose Load Temporary Add-on.
  3. Select the extracted manifest.json. Firefox removes this temporary installation at browser restart. A signed release is required for permanent installation.

Enable contribution

  1. Open a Tracker room, then open the extension popup from the browser toolbar.
  2. Choose room copies, global mesh contribution, or both, set allocations, then choose Save and run in background. Room mode saves that room's invitation on this device; global-only mode does not copy it.
  3. Wait for the popup to report the provider running. A pinned Tracker tab will remain open to serve data. Files must have retained browser copies to survive closing their source tab.
  4. Choose Stop background contribution to opt out and close the managed tab. Closing that tab while contribution is enabled causes the supervisor to reopen it.

Offline periods, sleep, browser shutdown and storage eviction interrupt availability. The extension does not make a durability guarantee.
